# موقع موسى للمعلومات — Moussa Info

موقع عربي متجاوب مبني بـ HTML وCSS وJavaScript، وجاهز للنشر مجاناً عبر GitHub Pages.

## الملفات
- `index.html`: محتوى الموقع وأقسامه.
- `style.css`: التصميم والألوان والتجاوب مع الهاتف.
- `script.js`: قائمة الهاتف والبحث والتصفية.
- `assets/favicon.svg`: أيقونة الموقع.

## النشر عبر GitHub Pages من الهاتف أو الحاسوب
1. ادخل إلى https://github.com وسجّل الدخول.
2. اضغط **New repository** وأنشئ مستودعاً باسم `moussa-info`.
3. اجعل المستودع **Public**.
4. ارفع محتويات هذا المجلد إلى المستودع، مع إبقاء `index.html` في الجذر.
5. افتح **Settings → Pages**.
6. في **Build and deployment** اختر **Deploy from a branch**.
7. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
8. بعد اكتمال النشر سيظهر رابط شبيه بـ `https://USERNAME.github.io/moussa-info/`.

## تعديلات مهمة قبل النشر
- استبدل رابط Facebook التجريبي في `index.html` برابط صفحتك الرسمية.
- غيّر المقالات النموذجية إلى مقالاتك الحقيقية.
- أضف صور مقالاتك داخل مجلد `assets` ثم اربطها في `index.html`.
- يمكنك تغيير اسم المستودع، لكن يجب أن يتوافق رابط GitHub Pages معه.

الموقع لا يحتاج إلى قاعدة بيانات أو اشتراك استضافة. إضافة المقالات حالياً تتم بتعديل ملف `index.html` ثم رفع التعديلات إلى GitHub.
